# Прогнозування врожайності на основі даних ДЗЗ

Прогнозування врожайності сільськогосподарських культур є однією з ключових задач сучасної агрономії. Для її вирішення використовують дані дистанційного зондування Землі, метеорологічні спостереження та методи машинного навчання.

## Джерела даних

- супутникові знімки Sentinel-2 (вегетаційний індекс NDVI);
- метеорологічні дані (температура, опади);
- польові спостереження.

## Методи

| Метод | Тип |
|---|---|
| Random Forest | ансамбль дерев рішень |
| SVM | метод опорних векторів |
| Нейронні мережі | глибоке навчання |
| XGBoost | градієнтний бустинг |
